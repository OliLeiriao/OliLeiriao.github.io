This is my personal website where I showcase my work profile and experience, as well as my hobbies, including photography and art.

The photography gallery reads image files directly from `Art&Img/Photos` and groups them by the location in each filename. Name files with the location followed by an optional number (for example, `Lisbon1.jpg`). New photos appear after they are pushed to the public GitHub repository.

The art gallery displays the works with captions defined in `art.js`; add each artwork's title, dimensions, and medium there to include it.
